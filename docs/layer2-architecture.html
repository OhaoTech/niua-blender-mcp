Four pillars Layer 2

1. Perception

Eyes return both image evidence and structured analytics: topology, UV checker, normals, silhouette, AO/cavity, lookdev.

2. Objective verification

Deterministic metrics decide whether the asset may advance. The judge cannot talk gates into passing.

3. Pipeline state

A lightweight registry tracks stage, gates, checkpoint, rollback, and next allowed actions.

4. Grounded knowledge

Human-reviewed stage standards are loaded as versioned packs; exemplar targets and deeper sources continue in later waves.

Big map Layer 2 waves

Stage pipeline and roadmap now share one spine

Waves 1-7 made the pipeline observable, gated, resumable, self-critiquing, material-ready, engine-ready, export-profile aware, and stricter about LOD/collision quality. Later waves deepen the same spine.

Intake, repair, retopo, UV Operational path with perception, quality metrics, gates, checkpoints, and self-critique. Waves 1-3
Optimize / LOD / collision Built engine-readiness metrics, LOD creation, collision proxies, split collision hulls, and configurable quality gates. Waves 4/7
Bake + material production Built PBR map preparation, normal/AO/cavity checks, material gates, texture-size checks, and atlas readiness. Wave 5
Export profiles Built generic, Godot, Unreal, and custom convention validation through parameters, not hardcoded engine names. Wave 6
Advanced LOD/collision quality Built LOD triangle-ratio checks, bounds-delta silhouette preservation, multi-hull collision creation, and collision coverage/tightness gates. Wave 7
Asset-class breadth Apply the same pipeline to hard-surface, organic/sculpt, generated cleanup, and from-scratch prop briefs. Wave 8
