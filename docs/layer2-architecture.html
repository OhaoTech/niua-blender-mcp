Four pillars Layer 2

1. Perception

Eyes return both image evidence and structured analytics: topology, UV checker, normals, silhouette, AO/cavity, lookdev.

2. Objective verification

Deterministic metrics decide whether the asset may advance. The judge cannot talk gates into passing.

3. Pipeline state

A lightweight registry tracks stage, gates, checkpoint, rollback, and next allowed actions.

4. Grounded knowledge

Human-reviewed standards and reference exemplars replace guesswork with cited production constraints.
